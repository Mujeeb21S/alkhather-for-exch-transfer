# الخضر للصرافة والتحويلات

موقع تعريفي ثابت لشركة محسن الخضر للصرافة والتحويلات النقدية (AL KHADHER EXCHANGE).
الترخيص رقم 486 صادر عن البنك المركزي اليمني. الصفحات للتعريف والمتابعة فقط، والصرف والتحويل يتمان في الفروع.

## التقنيات

- HTML
- CSS
- JavaScript
- Font Awesome عبر CDN
- وضع فاتح وداكن يُحفظ في المتصفح

## النشر على GitHub Pages

1. أنشئ مستودعاً جديداً على GitHub.
2. ارفع **محتويات هذا المجلد** إلى جذر المستودع بحيث يصبح `index.html` في الجذر، وليس داخل مجلد فرعي.
3. من المستودع: Settings ثم Pages.
4. اختر Branch: `main` و Folder: `/ (root)` ثم احفظ.
5. بعد دقيقة افتح الرابط الذي يظهر، مثل `https://USERNAME.github.io/REPO/`.

الروابط نسبية، لذلك يعمل الموقع على GitHub Pages وعلى فتح `index.html` مباشرة.
