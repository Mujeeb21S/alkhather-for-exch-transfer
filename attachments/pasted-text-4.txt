قم بتجهيز الموقع الإلكتروني الخاص بشركة "الخضر للصرافة والتحويلات" (AL KHADHER EXCHANGE) بشكل احترافي وشامل ليكون جاهزاً للنشر على GitHub Pages.

### المطلوب:

1. **تصدير الموقع كموقع ثابت (Static Website)**
   - حوّل الموقع بالكامل إلى ملفات HTML و CSS و JavaScript ثابتة فقط.
   - لا تستخدم أي تقنيات تحتاج سيرفر (مثل PHP أو قواعد بيانات أو Node.js).
   - اجعل جميع المسارات نسبية (Relative Paths) حتى يعمل الموقع بشكل صحيح على GitHub Pages.

2. **هيكل الملفات المطلوب**
   أنشئ الهيكل التالي بالضبط:
   ```
   /
   ├── index.html
   ├── about.html
   ├── services.html
   ├── rates.html
   ├── branches.html
   ├── transfers.html
   ├── contact.html
   ├── faq.html
   ├── privacy.html
   ├── terms.html
   ├── css/
   │   └── style.css
   ├── js/
   │   └── main.js
   ├── assets/
   └── README.md
   ```

3. **نظام التصميم + الوضع الداكن (Dark Mode) + زر التبديل**
   - أضف دعم كامل للوضع الداكن (Dark Mode).
   - أضف زر تبديل واضح وأنيق في الهيدر للتبديل بين الوضع الفاتح والداكن.
   - يجب أن يكون زر التبديل مرئياً وسهل الوصول إليه في جميع الصفحات.
   - استخدم أيقونة Font Awesome للتبديل:
     - أيقونة الشمس (`fa-sun`) عندما يكون الموقع في الوضع الداكن.
     - أيقونة القمر (`fa-moon`) عندما يكون الموقع في الوضع الفاتح.
   - احفظ اختيار المستخدم في `localStorage` حتى يبقى الوضع محفوظاً عند إعادة زيارة الموقع أو التنقل بين الصفحات.
   - يجب أن يعمل التبديل فوراً دون إعادة تحميل الصفحة.
   - الألوان المقترحة:
     - **الوضع الفاتح:**
       - الخلفية: #F8F6F1
       - البطاقات: #FFFFFF
       - النص: #1A1A1A
       - الأخضر الرئيسي: #0B3D2E
       - الذهبي: #C5A46E
     - **الوضع الداكن:**
       - الخلفية: #0F1419
       - البطاقات: #1A2332
       - النص: #E8E6E3
       - الأخضر: #2D6A4F
       - الذهبي: #D4AF37
   - يجب أن يتغير لون جميع العناصر (الخلفية، النصوص، البطاقات، الأزرار، الحدود، الهيدر، الفوتر) بشكل متناسق عند التبديل.

4. **تحسينات تجربة المستخدم (UX) والإتاحة**
   - اجعل التنقل سلساً وواضحاً مع قائمة موبايل احترافية.
   - أضف حالات تفاعل واضحة للأزرار (Hover, Active, Focus).
   - حسّن المسافات والتباعد بين العناصر لراحة العين.
   - أضف تأثيرات انتقالية خفيفة وسلسة فقط.
   - تأكد من دعم كامل لاتجاه RTL.
   - حسّن قابلية الوصول (Accessibility) قدر الإمكان (تباين ألوان جيد، عناصر قابلة للتركيز).
   - أضف رسائل توضيحية صغيرة تحت الحقول المهمة في النماذج.

5. **الأيقونات**
   - استخدم مكتبة Font Awesome عبر CDN.
   - استخدم أيقونات واضحة ومتناسقة في جميع أنحاء الموقع (الأمان، السرعة، الفروع، التتبع، التحويل، الهاتف، واتساب، إلخ).

6. **متطلبات التصميم والوظائف**
   - اجعل الموقع متجاوباً بالكامل (Responsive) على جميع الشاشات.
   - أضف زر واتساب ثابت وأنيق في أسفل الشاشة.
   - حافظ على جميع الوظائف الأساسية الموجودة حالياً (محول العملات، تتبع الحوالات، عرض الأسعار، الفروع، النماذج...).
   - أبرز رقم الترخيص 486 الصادر عن البنك المركزي اليمني بشكل واضح في الفوتر.
   - استخدم ظلالاً ناعمة وحواف مستديرة ناعمة.
   - حسّن قسم الـ Hero والبطاقات ليبدو أكثر احترافية.

7. **تحسينات SEO والأداء**
   - أضف Meta Tags أساسية ومناسبة في كل صفحة (Title, Description, Viewport).
   - استخدم عناوين واضحة ومنظمة (H1, H2, H3).
   - حسّن سرعة التحميل قدر الإمكان.
   - أضف `lang="ar"` و `dir="rtl"` في جميع الصفحات.

8. **تحسينات تقنية للنشر على GitHub Pages**
   - استخدم روابط نسبية فقط في جميع الملفات.
   - تأكد من أن الموقع يعمل بشكل صحيح عند فتح `index.html` مباشرة.
   - اجعل الكود نظيفاً ومنظماً وسهل التعديل لاحقاً.
   - أضف تعليقات توضيحية بسيطة في الملفات الرئيسية.

9. **ملف README.md**
   يجب أن يحتوي على:
   - اسم المشروع ووصفه.
   - طريقة النشر على GitHub Pages خطوة بخطوة.
   - التقنيات المستخدمة (HTML, CSS, JavaScript, Font Awesome, Dark Mode).
   - ملاحظة أن الموقع إرشادي والتنفيذ الفعلي يتم في الفروع فقط.

10. **ضوابط مهمة**
    - لا تضف أي وظائف تنفيذ مالي حقيقية (الصرف والتحويل يتم في الفروع فقط).
    - حافظ على الخصوصية العالية في صفحة تتبع الحوالات (لا يتم عرض الأسماء أو المبالغ).
    - يجب أن يعمل زر تبديل الوضع الداكن بسلاسة في جميع الصفحات.
    - ركز على الثقة والأمان والوضوح والاحترافية.

قم بتجهيز الموقع بالكامل كموقع ثابت جاهز للرفع على مستودع GitHub ونشره عبر GitHub Pages، مع زر تبديل واضح واحترافي للوضع الداكن وتحسينات شاملة في التصميم وتجربة المستخدم.
