6. التكامل مع نظام الخضر للصرافة

صمم الموقع ليكون قابلاً للتكامل مستقبلاً مع النظام المالي والمحاسبي المركزي لشركة الخضر للصرافة والتحويلات.

يجب تجهيز طبقة API منظمة تسمح بالتكامل مع:

- قاعدة بيانات العملاء.
- أسعار العملات.
- نظام الحوالات.
- نظام الفروع.
- نظام الوكلاء.
- الإشعارات.
- التقارير.

المتطلبات:

- RESTful API.
- توثيق API باستخدام OpenAPI/Swagger.
- مصادقة آمنة.
- صلاحيات وصول واضحة.
- Rate Limiting.
- معالجة الأخطاء.
- التحقق من المدخلات.
- تسجيل العمليات.
- Idempotency للعمليات الحساسة.
- Webhooks عند الحاجة.

مهم جداً: لا تنشئ تكاملاً وهمياً مع البنوك أو شركات التحويل أو مزودي خدمات الدفع. لا تدّعِ تنفيذ عمليات مالية حقيقية دون وجود API رسمي معتمد وبيانات اتصال واختبارات فعلية.

14. تعليمات التنفيذ النهائية

ابدأ أولاً بتحليل المتطلبات وتصميم هيكل المشروع وقاعدة البيانات وتدفقات المستخدم.

بعد ذلك نفّذ المشروع على مراحل منظمة، مع المحافظة على ترابط جميع المكونات.

لا تكتفِ بتصميم واجهات Static أو صفحات HTML شكلية.

المطلوب نظام ويب فعلي Full-Stack، تعمل وظائفه من خلال Backend وDatabase حقيقيين.

لا تستخدم بيانات مالية وهمية على أنها بيانات مباشرة.

لا تترك روابط أو أزراراً غير فعالة.

لا تختصر المتطلبات الجوهرية بحجة تسريع التنفيذ.

اجعل جميع المكونات قابلة للتطوير والتوسع مستقبلاً.

معيار القبول النهائي:

يجب أن يكون الناتج موقعاً إلكترونياً مؤسسياً متكاملاً لشركة الخضر للصرافة والتحويلات، بمستوى جودة تصميمي وتقني يليق بمؤسسة مالية محترفة، ويجمع بين الهوية المؤسسية، وسهولة الاستخدام، والأمان، وقابلية التكامل مع النظام المالي المركزي للشركة.
